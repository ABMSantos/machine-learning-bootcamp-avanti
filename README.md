## 1. O que é Machine Learning?

Machine Learning é uma área da inteligência artificial que permite que computadores aprendam a partir de dados.

Em vez de receber regras prontas, o sistema analisa exemplos e aprende padrões sozinho. Com isso, ele consegue fazer previsões ou classificações.

Um exemplo simples são aplicativos de música ou filmes, que observam o que gostamos e passam a recomendar conteúdos parecidos. Outro exemplo é um programa que aprende a diferenciar fotos de gatos e cachorros após ver vários exemplos.

---

## 2. Conjunto de treinamento, validação e teste

Para criar um modelo de machine learning, os dados costumam ser divididos em três partes:

### Conjunto de treinamento  
É usado para ensinar o modelo. Aqui ele aprende os padrões presentes nos dados.

### Conjunto de validação  
Serve para acompanhar o desempenho durante o desenvolvimento e ajustar o modelo.

### Conjunto de teste  
É utilizado no final para verificar se o modelo realmente funciona com dados novos.

De forma simples:
- Treinamento: aprende  
- Validação: ajusta  
- Teste: avalia  

---

## 3. Como lidar com dados ausentes

Dados ausentes são informações que estão vazias ou incompletas.

Algumas formas comuns de lidar com isso são:

- Remover linhas com poucos valores faltantes.
- Preencher os campos vazios com a média ou valor mais frequente.
- Criar uma categoria como “desconhecido”.
- Em casos mais avançados, estimar o valor com base em outros dados.

A escolha depende da quantidade de dados ausentes e da importância dessas informações.

---

## 4. O que é matriz de confusão

A matriz de confusão é uma tabela usada para comparar o que o modelo previu com o que realmente aconteceu.

Ela mostra:

- Quando o modelo acerta.
- Quando erra.
- Quando prevê algo que não era verdadeiro.
- Quando deixa de identificar algo que era verdadeiro.

Com essa matriz é possível entender melhor o desempenho do modelo e calcular métricas como acurácia.

Um exemplo seria na área da saúde, onde ela ajuda a visualizar se um exame automático está acertando ou errando diagnósticos.

## 5. Áreas onde o Machine Learning pode ser aplicado

Mesmo sendo iniciante, considero muito interessantes as aplicações em:

- Saúde: apoio a diagnósticos e análise de exames.
- Agricultura: monitoramento de plantações e previsão de colheitas.
- Manufatura: prevenção de falhas em máquinas.
- Construção civil: estimativa de custos e riscos.
- Mobilidade urbana: melhoria do trânsito e prevenção de acidentes.

O machine learning permite transformar dados em informações úteis para apoiar decisões.
